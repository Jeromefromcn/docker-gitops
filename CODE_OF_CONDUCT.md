# Code of Conduct

This is a personal infrastructure repository. Be respectful and constructive
in issues, pull requests and discussions. Harassment, personal attacks and
discriminatory language are not tolerated.

The maintainer may edit, hide or remove comments, and block users, that do not
follow this standard.

To report a problem, use GitHub's "Report content" feature on the offending
comment, or contact the maintainer through their GitHub profile.
